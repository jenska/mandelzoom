# mandelzoom
Ebiten Mandelbrot realtime zoom in Go

## Run
```bash
make run
```

## Make targets
- `make build` - build binary to `bin/mandelzoom`
- `make run` - run the application
- `make tidy` - tidy Go modules
- `make fmt` - format Go source files
- `make test` - run tests
- `make clean` - remove build artifacts
